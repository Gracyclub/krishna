# Krishna Neon Art & Visualizer Animation 🦚

An interactive Computer Vision visualizer built with **Python**, **OpenCV**, and **NumPy**. This script takes an image (`krishna.jpg`), extracts its contours, and renders a multi-stage glowing visual animation.

---

## ✨ Visual Effects Included

1. **Neon Sketch Drawing:** Dynamically reconstructs the image contour by contour using particle drawing and a Gaussian neon glow filter.
2. **Smooth 360° Rotation:** Rotates the image seamlessly around its center with added bloom/glow effects.
3. **Pulsing / Breathing Glow:** Smooth zoom-in and zoom-out affine transformations with variable kernel blur to simulate a breathing light aura.

---
## 🚀 Getting Started

### 1. Prerequisites
Ensure you have Python 3.x installed.

### 2. Installation
Clone the repository and install the dependencies:

```bash
git clone https://github.com/Gracyclub/krishna.git
cd krishna
pip install opencv-python numpy
```

### 3. Usage

1. Place your target image in the root directory and name it krishna.jpg
2. Run the Python script:

```bash
python krishna.py
```

3. Let the animation play completely, or close the window to exit.
